# 本当の時給（real-hourly-rate）

案件ごとに、報酬・作業の時間・修正やり直しの時間・打合せの時間・経費を入れると、「作業だけの時給」と「全部含めた時給」を並べて出す静的ページです（100日100プロダクト Day069）。

- 入力した数字はブラウザの中だけで処理し、サーバーには送信せず、保存もしません（通信は閲覧数の計測のみ）
- AIは使っていません（四則演算のみ）
- 手取りの時給ではありません。税金・社会保険・移動・営業や見積の時間・待ち時間は入っていません
- 「目安より低い」の印は、自分で入れた基準の時給と比べた結果です。この道具は水準を提案しません

## 使い方
`index.html` をブラウザで開きます。ビルド不要（1ファイル）。

## 開発用（source/）
- `run-checks.js`: 計算の検算（`node source/run-checks.js`）
- `shoot.js` / `cdp.js`: 投稿カード用の画面撮影（Chrome headless）
